# Apple long-form (built into macOS)

The engine macOS uses for Notes and Voice Memos, meant for recordings. Nothing to download, and it uses a fraction of the memory every other model needs - about 20 MB against hundreds or thousands.

| | |
| --- | --- |
| **Best for** | Getting started without downloading anything, and for recordings in the languages it covers |
| **Speed** | 53 to 85 times real time |
| **Memory** | About 20 MB |
| **Download** | None, though macOS fetches a language the first time you use it |
| **Live typing** | Yes |
| **Needs** | macOS 26 or later |

## Languages

macOS 27 added 15 Indian languages to this engine - Bengali, Gujarati, Hindi, Kannada, Kashmiri, Maithili, Malayalam, Marathi, Nepali, Odia, Punjabi, Tamil, Telugu and Urdu - which the list above does not yet show.

It has no model for Croatian, Czech, Polish, Russian, Slovak or Ukrainian. Ask for one of those and Speech uses the dictation engine instead, which is weaker.

## Word Error Rate (WER)

Word error rate (WER) is the share of words you would have to fix, so lower is better. Measured on read speech; your own recordings can differ.

| | This engine | Apple dictation | Best downloadable model |
| --- | --- | --- | --- |
| English | 8.0% | 12.9% | 3.7% |
| German | 6.5% | 13.0% | 4.1% |
| Spanish | 4.5% | 7.4% | 3.1% |
| French | 7.5% | 16.5% | 4.6% |

It is the better of the two built-in engines everywhere both exist, by 3 to 9 points.

## Choosing

**Pick it if** you want to start immediately, or disk space and memory are tight. In its languages it is the best transcription you can have without downloading anything.

**Skip it if** accuracy matters more than convenience: a downloaded model roughly halves the errors in every language above.

**Worth knowing**

- **It arrived in macOS 26.** On anything older it does not exist, and Speech says so rather than offering it.
- **A macOS update can change it, but so far has not.** The same recordings measured on macOS 26.6.2, 26.7.0 and 27.0 gave identical accuracy to two decimal places in every language.
- It produces word-level timings, so it can make subtitles.
- It cannot be given your own vocabulary, and learns nothing from your corrections.
